# Credits — Battalions in Space

## Original work (made for this game)
- Game design, code, factions, characters, ships, planets, galaxy and all text.
- Every 3D model (soldiers, heroes, vehicles, starfighters, capital ships, props, terrain) is generated in code from simple shapes (`Assets/Scripts/Core/MeshKit.cs`).
- Every sound effect and the menu march are synthesised at start-up in code (`Assets/Scripts/Core/Sfx.cs`).
- Shaders `BIS/Lit`, `BIS/Fx`, `BIS/Sky` (`Assets/Resources/Shaders`).

## Inspiration
Mechanics are inspired by the classic mid-2000s team-based "battlefront" shooters (command posts, reinforcement tickets, heroes, space battles with boarding, galactic campaign). No names, characters, designs, sounds or logos from any existing game or franchise are used.
